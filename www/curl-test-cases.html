Curl tests

Basic HTTP Tests

Serve a page

Expected: The index page loads successfully. 

curl localhost:8080/index.html

Tests the basic GET path and static file response.

Reject an unsupported body

Expected: The server returns 415. 

curl -X POST -H "Content-Type: plain/text" --data "1234567890" localhost:8080/

Tests content-type validation for a POST request.

Delete an upload

Expected: The server handles the DELETE request. 

curl -X DELETE localhost:8080/upload/upload.txt

Tests the DELETE route for an upload target.

Reject an unknown method

Expected: The server returns 405. 

curl -X UNKNOWN localhost:8080

Tests that unsupported HTTP methods are rejected.

Basic GET: index file

Expected: 200 

curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/index.html

Checks that a static file can be fetched directly.

Root resolves to index

Expected: 200 

curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/

Checks the configured index file for the root location.

Routing & Config Tests

Redirect route

Expected: 302 with Location: /redirected.html 

curl -sS -i http://127.0.0.1:8080/redirect | sed -n "1,12p"

Tests redirect status and response headers.

Return directive

Expected: 302 with Location: /error_pages/300.html 

curl -sS -i http://127.0.0.1:8080/testing_return | sed -n "1,12p"

Tests a configured return rule and its target.

Autoindex directories

Expected: Both directories return 200. 

curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/upload/
curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/imgs/

Tests directory listing responses for configured folders.

Custom 404 page

Expected: 404 with custom HTML content. 

curl -sS http://127.0.0.1:8080/nope-404 | sed -n "1,8p"

Checks both the missing route status and its error-page body.

Query-string behavior

Expected: 404 in the current configuration. 

curl -sS -o /dev/null -w "%{http_code}\n" "http://127.0.0.1:8080/index.html?x=1"

Checks how a query string affects static-file resolution.

Method & Request Body Tests

POST to the root

Expected: 415 

curl -sS -o /dev/null -w "%{http_code}\n" -X POST -H "Content-Type: text/plain" --data "hello-webserv" http://127.0.0.1:8080/

Tests whether the route rejects this request content type.

POST not allowed on uploads

Expected: 405 

curl -sS -o /dev/null -w "%{http_code}\n" -X POST -H "Content-Type: text/plain" --data "x" http://127.0.0.1:8080/upload/

Tests method restrictions on the upload directory.

Body too large

Expected: 413 for a 6 MB body. 

dd if=/dev/zero bs=1M count=6 2>/dev/null | tr "\000" "a" | curl -sS -o /dev/null -w "%{http_code}\n" -X POST -H "Content-Type: application/octet-stream" --data-binary @- http://127.0.0.1:8080/

Tests the client_max_body_size override of 3 MB configured for the root location.

Missing file deletion

Expected: 404 

curl -sS -o /dev/null -w "%{http_code}\n" -X DELETE http://127.0.0.1:8080/upload/does-not-exist.txt

Tests the error response when DELETE targets no file.

HEAD and OPTIONS

Expected: Both requests return 405. 

curl -sS -o /dev/null -w "%{http_code}\n" -I http://127.0.0.1:8080/index.html
curl -sS -o /dev/null -w "%{http_code}\n" -X OPTIONS http://127.0.0.1:8080/

Tests handling for methods that are not configured.

Malformed & Path Tests

Path traversal

Expected: 400 

curl --path-as-is -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/../secret.html

Tests that parent-directory traversal is rejected.

Double slash and backslash

Expected: Both requests return 400. 

curl --path-as-is -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080//etc/passwd
curl --path-as-is -sS -o /dev/null -w "%{http_code}\n" "http://127.0.0.1:8080/..\secret"

Tests path normalization and alternate traversal attempts.

Malformed raw request

Expected: HTTP/1.1 400 Bad request 

printf "GET HTTP/1.1\r\nHost: localhost\r\n\r\n" | nc 127.0.0.1 8080 | head -n 1

Tests parser validation using an incomplete request line.

CGI endpoint

Socket & Connection Tests

Basic socket connection

Expected: HTTP/1.1 200 OK 

printf "GET / HTTP/1.1\r\nHost: localhost\r\n\r\n" | nc 127.0.0.1 8080 | head -n 1

Opens a raw TCP connection, sends a valid HTTP request, and checks that the listener accepts and serves the client.

Server is listening

Expected: A listening socket appears on 127.0.0.1:8080. 

ss -ltn | grep ":8080"

Checks that socket creation, bind, and listen succeeded.

Idle connection does not block

Expected: The second request immediately returns 200. 

(sleep 20 | nc 127.0.0.1 8080 >/dev/null) &
sleep 1
curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/

Keeps one client connected without sending anything and checks that another client is still handled immediately.

Repeated connections

Expected: All requests return 200. 

for i in $(seq 1 50); do
    curl -sS -o /dev/null -w "%{http_code} " http://127.0.0.1:8080/
done
echo

Repeatedly opens and closes client sockets and helps test safe fd reuse.

RECV & Request Buffer Tests

Fragmented request

Expected: HTTP/1.1 200 OK 

(
    printf "GET /index.html HTTP/1.1\r\n"
    sleep 1
    printf "Host: localhost\r\n"
    sleep 1
    printf "User-Agent: slow-client\r\n"
    sleep 1
    printf "\r\n"
) | nc 127.0.0.1 8080 | head -n 1

Sends one HTTP request in several pieces. Multiple recv calls must be combined before the request is processed.

Very fragmented request

Expected: HTTP/1.1 200 OK 

(
    printf "GET "
    sleep 1
    printf "/index.html "
    sleep 1
    printf "HTTP/1.1\r\n"
    sleep 1
    printf "Host: localhost\r\n"
    sleep 1
    printf "\r\n"
) | nc 127.0.0.1 8080 | head -n 1

Fragments even the request line itself. Tests that recv boundaries are not treated as HTTP message boundaries.

Client disconnect during receive

Expected: The client is cleaned up and the next request returns 200. 

timeout 2 sh -c 'printf "GET / HTTP/1.1\r\nHost:" | nc 127.0.0.1 8080' || true
curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/

Disconnects while a request is incomplete and checks recv EOF/client cleanup.

Multiple receive buffers

Expected: All requests return 200. 

for i in $(seq 1 20); do
    curl -sS -o /dev/null -w "%{http_code} " http://127.0.0.1:8080/index.html &
done
wait
echo

Tests that every Client maintains its own receive buffer and state.

SEND & Response Tests

Create a large response file

Expected: A 20 MB file is created in www/. 

dd if=/dev/urandom of=www/large.bin bs=1M count=20

Creates a large static file for testing partial send behavior.

Large response integrity

Expected: FILES MATCH 

curl -sS http://127.0.0.1:8080/large.bin -o downloaded.bin
cmp www/large.bin downloaded.bin && echo "FILES MATCH"

Tests bytes-sent tracking and verifies that a large response is not truncated, duplicated, or corrupted.

Large GET is not body-size limited

Expected: 200, not 413. 

curl -sS -o /dev/null -w "%{http_code} %{size_download}\n" http://127.0.0.1:8080/large.bin

Confirms that client_max_body_size limits incoming request bodies, not outgoing static GET responses.

Slow receiver

Expected: The normal request returns 200 while the slow download continues. 

curl -sS --limit-rate 100k http://127.0.0.1:8080/large.bin -o /tmp/slow.bin &
sleep 1
curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/

Tests POLLOUT and non-blocking send behavior when one receiver reads slowly.

Client disconnect during send

Expected: The server stays alive and the final request returns 200. 

curl -sS http://127.0.0.1:8080/large.bin 2>/dev/null | head -c 1024 >/dev/null || true
curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/

Stops reading after part of a large response and tests send-error/client cleanup.

Response Content-Length

Expected: The file size and Content-Length match. 

stat -c "%s" www/large.bin
curl -sS -D - -o /dev/null http://127.0.0.1:8080/large.bin | grep -i "Content-Length"

Checks that the response advertises the correct number of bytes.

Timeout Tests

Incomplete request timeout

Expected: HTTP/1.1 408 Request Timeout 

(
    printf "GET / HTTP/1.1\r\n"
    printf "Host: localhost\r\n"
    sleep 35
) | nc 127.0.0.1 8080 | head -n 1

Never sends the final blank line, leaving the HTTP request incomplete.

Completely idle client timeout

Expected: The idle connection is closed cleanly after the timeout. 

sleep 35 | nc 127.0.0.1 8080

Connects to the listener but never sends a request.

Activity resets timeout

Expected: HTTP/1.1 200 OK 

(
    printf "GET /index.html "
    sleep 20
    printf "HTTP/1.1\r\n"
    sleep 20
    printf "Host: localhost\r\n\r\n"
) | nc 127.0.0.1 8080 | head -n 1

The complete request takes more than 30 seconds, but activity occurs before each timeout interval. Tests lastActivity updates.

CGI timeout

Expected: 504 

curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/timeout_script/timeout_test.py

A CGI process that exceeds its timeout should return 504 Gateway Timeout.

CGI timeout does not block clients

Expected: NORMAL: 200, followed later by CGI: 504. 

curl -sS -o /dev/null -w "CGI: %{http_code}\n" http://127.0.0.1:8080/timeout_script/timeout_test.py &
sleep 1
curl -sS -o /dev/null -w "NORMAL: %{http_code}\n" http://127.0.0.1:8080/
wait

Tests that slow CGI execution does not block the poll loop.

Server works after timeout

Expected: Timeout handling completes and the next request returns 200. 

(
    printf "GET / HTTP/1.1\r\nHost: localhost\r\n"
    sleep 35
) | nc 127.0.0.1 8080 | head -n 1

curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/

Checks that removing a timed-out Client does not damage later connections.

Client Lifecycle & Concurrency Tests

20 simultaneous clients

Expected: All requests return 200. 

for i in $(seq 1 20); do
    curl -sS -o /dev/null -w "%{http_code} " http://127.0.0.1:8080/ &
done
wait
echo

Tests poll handling with many Client objects active at once.

100 client stress test

Expected: Requests complete successfully and the server remains alive. 

seq 1 100 | xargs -n1 -P20 sh -c \
'curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/'

Applies pressure to accept, poll, recv, send, and client cleanup.

Idle client plus active clients

Expected: All active clients return 200. 

(sleep 35 | nc 127.0.0.1 8080 >/dev/null) &
sleep 1

for i in $(seq 1 20); do
    curl -sS -o /dev/null -w "%{http_code} " http://127.0.0.1:8080/ &
done

wait
echo

Tests that one inactive client never blocks active ones.

File descriptor reuse

Expected: All requests return 200. 

for i in $(seq 1 100); do
    curl -sS -o /dev/null -w "%{http_code} " http://127.0.0.1:8080/ || break
done
echo

Encourages the OS to reuse fd numbers and checks that stale Client state is never associated with a new connection.

Client disconnect during CGI

Expected: The server stays alive and the final request returns 200. 

curl --max-time 1 -sS http://127.0.0.1:8080/timeout_script/timeout_test.py >/dev/null || true
sleep 35
curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/

Removes the HTTP client before its CGI finishes and tests cleanup of CGI-to-client mappings.

Check for fd leaks

Expected: Before and after counts remain approximately the same. 

pid=$(pgrep -n webserv)

echo "Before:"
ls /proc/$pid/fd | wc -l

for i in $(seq 1 100); do
    curl -sS http://127.0.0.1:8080/ >/dev/null
done

sleep 1

echo "After:"
ls /proc/$pid/fd | wc -l

Checks that completed clients do not leave sockets or descriptors open.

Mixed workload

Expected: The final line prints SERVER STILL ALIVE: 200. 

curl -sS http://127.0.0.1:8080/large.bin -o /tmp/large-test.bin &
curl -sS http://127.0.0.1:8080/confetti.py >/dev/null &
curl -sS http://127.0.0.1:8080/timeout_script/timeout_test.py >/dev/null &

for i in $(seq 1 20); do
    curl -sS http://127.0.0.1:8080/ >/dev/null &
done

wait

curl -sS -o /dev/null -w "SERVER STILL ALIVE: %{http_code}\n" http://127.0.0.1:8080/

Runs static responses, CGI, timeout CGI, and normal clients together to exercise most of the event loop simultaneously.
