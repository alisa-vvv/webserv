Curl test cases

Curl tests

Serve a page

Expected: The index page loads successfully.

curl localhost:8080/index.html

Tests the basic GET path and static file response.

Reject an unsupported body

Expected: The server returns 415.

curl -X POST -H "Content-Type: plain/text" --data "1234567890" localhost:8080/

Tests content-type validation for a POST request.

Delete an upload

Expected: The server handles the DELETE request.

curl -X DELETE localhost:8080/upload/upload.txt

Tests the DELETE route for an upload target.

Reject an unknown method

Expected: The server returns 405.

curl -X UNKNOWN localhost:8080

Tests that unsupported HTTP methods are rejected.

Basic GET: index file

Expected: 200

curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/index.html

Checks that a static file can be fetched directly.

Root resolves to index

Expected: 200

curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/

Checks the configured index file for the root location.

Redirect route

Expected: 302 with Location: /redirected.html

curl -sS -i http://127.0.0.1:8080/redirect | sed -n "1,12p"

Tests redirect status and response headers.

Return directive

Expected: 302 with Location: /error_pages/300.html

curl -sS -i http://127.0.0.1:8080/testing_return | sed -n "1,12p"

Tests a configured return rule and its target.

Autoindex directories

Expected: Both directories return 200.

curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/upload/
curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/imgs/

Tests directory listing responses for configured folders.

Custom 404 page

Expected: 404 with custom HTML content.

curl -sS http://127.0.0.1:8080/nope-404 | sed -n "1,8p"

Checks both the missing route status and its error-page body.

POST to the root

Expected: 415

curl -sS -o /dev/null -w "%{http_code}\n" -X POST -H "Content-Type: text/plain" --data "hello-webserv" http://127.0.0.1:8080/

Tests whether the route rejects this request content type.

POST not allowed on uploads

Expected: 405

curl -sS -o /dev/null -w "%{http_code}\n" -X POST -H "Content-Type: text/plain" --data "x" http://127.0.0.1:8080/upload/

Tests method restrictions on the upload directory.

Body too large

Expected: 413 for a 6 MB body.

dd if=/dev/zero bs=1M count=6 2>/dev/null | tr "\000" "a" | curl -sS -o /dev/null -w "%{http_code}\n" -X POST -H "Content-Type: application/octet-stream" --data-binary @- http://127.0.0.1:8080/

Tests the configured client_max_body_size limit of 5 MB.

Missing file deletion

Expected: 404

curl -sS -o /dev/null -w "%{http_code}\n" -X DELETE http://127.0.0.1:8080/upload/does-not-exist.txt

Tests the error response when DELETE targets no file.

HEAD and OPTIONS

Expected: Both requests return 405.

curl -sS -o /dev/null -w "%{http_code}\n" -I http://127.0.0.1:8080/index.html
curl -sS -o /dev/null -w "%{http_code}\n" -X OPTIONS http://127.0.0.1:8080/

Tests handling for methods that are not configured.

Path traversal

Expected: 400

curl --path-as-is -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/../secret.html

Tests that parent-directory traversal is rejected.

Double slash and backslash

Expected: Both requests return 400.

curl --path-as-is -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080//etc/passwd
curl --path-as-is -sS -o /dev/null -w "%{http_code}\n" "http://127.0.0.1:8080/..\secret"

Tests path normalization and alternate traversal attempts.

CGI endpoint

Expected: 200

curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/confetti.py

Checks that a configured Python CGI script executes.

Timeout CGI endpoint

Expected: 408

curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/timeout_script/timeout_test.py

Tests the server timeout for a script that does not finish.

Query-string behavior

Expected: 404 in the current configuration.

curl -sS -o /dev/null -w "%{http_code}\n" "http://127.0.0.1:8080/index.html?x=1"

Checks how a query string affects static-file resolution.

Malformed raw request

Expected: HTTP/1.1 400 Bad request

printf "GET HTTP/1.1\r\nHost: localhost\r\n\r\n" | nc 127.0.0.1 8080 | head -n 1

Tests parser validation using an incomplete request line.
