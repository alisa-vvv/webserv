how it works:

server 1 → 127.0.0.1:8080
server 2 → 127.0.0.1:8080
server 3 → 127.0.0.1:9000

You need only two listeners:

Listener A → 127.0.0.1:8080 → server 1 and server 2
Listener B → 127.0.0.1:9000 → server 3

Server::setup()
    ├── builds vector<Listener>
    └── calls Listener::setup() for each listener

Listener::setup()
    └── socket(), bind(), listen()

Listener
    socket()
    setsockopt()
    fcntl()
    bind()
    listen()
    close its own fd

Server
    owns vector<Listener>
    owns vector<pollfd>
    runs poll()
    accepts clients
    stores clients
    receives and sends data
